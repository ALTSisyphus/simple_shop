# Skystore

Skystore — учебный интернет-магазин на Django с каталогом товаров и блогом.

Проект использует Django, PostgreSQL, Poetry, Bootstrap и Pillow.

## Приложение catalog

В приложении `catalog` реализованы:

* вывод списка товаров на главной странице;
* пагинация по 6 товаров на странице;
* карточки товаров с изображением, названием, ценой и кратким описанием;
* детальная страница товара;
* форма создания нового товара;
* загрузка изображений товаров;
* проверка обязательных полей формы;
* проверка положительной цены;
* отображение ошибок валидации;
* автоматическое назначение категории «Без категории»;
* страница контактов;
* обработка формы обратной связи;
* общий базовый шаблон и главное меню.

Контроллеры приложения `catalog` реализованы через CBV:

* `ListView` — список товаров;
* `DetailView` — детальная страница товара;
* `CreateView` — создание товара;
* `View` — страница контактов.

## Приложение blog

В приложении `blog` реализована модель блоговой записи со следующими полями:

* заголовок;
* содержимое;
* превью;
* дата создания;
* признак публикации;
* количество просмотров.

Полный CRUD блоговых записей реализован через CBV:

* `ListView` — список статей;
* `DetailView` — просмотр статьи;
* `CreateView` — создание статьи;
* `UpdateView` — редактирование статьи;
* `DeleteView` — удаление статьи.

Дополнительная логика блога:

* в списке отображаются только опубликованные статьи;
* при открытии статьи увеличивается счётчик просмотров;
* после создания открывается созданная статья;
* после редактирования открывается изменённая статья;
* после удаления выполняется переход к списку статей;
* поддерживается загрузка изображений для превью;
* шаблоны блога наследуют общий базовый шаблон;
* ссылки на блог добавлены в главное меню.

## Установка зависимостей

Для управления зависимостями используется Poetry.

Установка зависимостей:

    poetry install --no-root

Проверка конфигурации Poetry:

    poetry check

## Настройка окружения

Создайте локальный файл `.env` на основе `.env.example`:

    cp .env.example .env

После копирования замените значения-заглушки своими локальными настройками:

    SECRET_KEY=ваш-секретный-ключ
    DEBUG=True

    DB_NAME=имя-базы-данных
    DB_USER=пользователь-базы-данных
    DB_PASSWORD=пароль-пользователя
    DB_HOST=localhost
    DB_PORT=5432

Файл `.env` содержит локальные секреты и не должен добавляться в Git.

## Миграции

Создание миграций после изменения моделей:

    poetry run python manage.py makemigrations

Применение миграций:

    poetry run python manage.py migrate

Проверка состояния миграций:

    poetry run python manage.py showmigrations

## Запуск проекта

Проверка конфигурации Django:

    poetry run python manage.py check

Запуск сервера разработки:

    poetry run python manage.py runserver

После запуска проект доступен по адресу:

    http://127.0.0.1:8000/

Основные страницы:

    /                    — каталог товаров
    /products/create/    — создание товара
    /contacts/           — страница контактов
    /blogs/              — список опубликованных статей
    /blogs/create/       — создание статьи

## Тесты

Тесты приложения `catalog`:

    poetry run python manage.py test catalog

Тесты приложения `blog`:

    poetry run python manage.py test blog

Все тесты проекта:

    poetry run python manage.py test

Тестами проверяются:

* страницы каталога;
* пагинация;
* создание товаров;
* валидация формы товара;
* модель блоговой записи;
* фильтрация опубликованных статей;
* увеличение счётчика просмотров;
* создание, просмотр, редактирование и удаление статей;
* перенаправления после операций CRUD;
* ответы `404` для неизвестных объектов.
