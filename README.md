# Skystore

Skystore — учебный интернет-магазин на Django с каталогом товаров и блогом.

Проект использует Django, PostgreSQL, Poetry, Bootstrap и Pillow.

## Приложение catalog

В приложении `catalog` реализованы:

* вывод списка товаров на главной странице;
* пагинация по 6 товаров на странице;
* карточки товаров с изображением, названием, ценой и кратким описанием;
* детальная страница товара;
* форма создания нового товара;
* загрузка изображений товаров;
* проверка обязательных полей формы;
* проверка положительной цены;
* отображение ошибок валидации;
* автоматическое назначение категории «Без категории»;
* страница контактов;
* обработка формы обратной связи;
* общий базовый шаблон и главное меню.

Контроллеры приложения `catalog` реализованы через CBV:

* `ListView` — список товаров;
* `DetailView` — детальная страница товара;
* `CreateView` — создание товара;
* `View` — страница контактов.

## Приложение blog

В приложении `blog` реализована модель блоговой записи со следующими полями:

* заголовок;
* содержимое;
* превью;
* дата создания;
* признак публикации;
* количество просмотров.

Полный CRUD блоговых записей реализован через CBV:

* `ListView` — список статей;
* `DetailView` — просмотр статьи;
* `CreateView` — создание статьи;
* `UpdateView` — редактирование статьи;
* `DeleteView` — удаление статьи.

Дополнительная логика блога:

* в списке отображаются только опубликованные статьи;
* при открытии статьи увеличивается счётчик просмотров;
* после создания открывается созданная статья;
* после редактирования открывается изменённая статья;
* после удаления выполняется переход к списку статей;
* поддерживается загрузка изображений для превью;
* шаблоны блога наследуют общий базовый шаблон;
* ссылки на блог добавлены в главное меню.

## Установка зависимостей

Для управления зависимостями используется Poetry.

Установка зависимостей:

    poetry install --no-root

Проверка конфигурации Poetry:

    poetry check
