# Skystore

Skystore — учебный интернет-магазин, разработанный на Django.

В проекте реализованы:

* вывод списка товаров на главной странице;
* карточки товаров с изображением, названием и кратким описанием;
* детальная страница товара;
* переход с главной страницы на страницу товара и обратно;
* базовый шаблон с общей шапкой, меню и подвалом;
* отдельный подшаблон главного меню;
* форма добавления нового товара;
* загрузка изображений;
* проверка обязательных полей формы;
* отображение ошибок валидации;
* сохранение товаров в базе данных;
* пагинация списка товаров по 6 товаров на странице;
* автоматические тесты основных страниц и формы.

Проект использует Django, PostgreSQL, Poetry, Bootstrap и Pillow.
